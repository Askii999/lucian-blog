# 整理说明（2026-11-02）

这是从原有 freeme.fun 工程整理出的独立文件写作版本。原目录及线上站点没有被替换。

- 以路由入口和 TypeScript/CSS 引用图确定运行文件；没有沿用父目录 Git 历史。
- 未带入旧 Almanac/Paste-up 等主题、停用的特效和宠物、旧后台界面、数据库认证、旧示例文章与历史一次性部署脚本。
- 保留 Coral 设计变量、当前布局/动效、三个 BenchArt 模型及其交互代码、归档/标签独立路由、语言主题切换和 Giscus。
- 当前公开的 1 篇文章、关于页、公开资料和 dustella 友链迁入 content/；文章标题和正文与迁移时公开接口内容核对一致。

- CI 使用只读权限；部署工作流只由 main push/手动触发，并默认禁用。尚需建远程仓库、配置 GitHub Secrets/分支规则及服务器一次性安装。

本次按引用关系安全清理，不盲删可能被动态生成 class 使用的 Coral 选择器。此说明不意味着已经执行远端 GitHub Actions 或 Linux 上线验收。
